# PonticheAge

Server, launcher e addon client scritti da zero per **ArcheAge 9.0.2.9 (XLGames KX, r590504, 2022-09-21)**.

Niente codice AAEmu: il protocollo e le regole del gioco si ricavano dal client (Ghidra) e dai suoi dati.

| Cartella | Contenuto |
|---|---|
| `wiki/` | Vault Obsidian con tutta la documentazione (aprilo con Obsidian; parti da `wiki/index.md`) |
| `tools/` | Script di reverse engineering (Ghidra) e strumenti di sviluppo |
| `server/` | Server di gioco (in arrivo) |
| `launcher/` | Launcher per i giocatori (in arrivo) |
| `client-addons/` | Addon del client: prestazioni, correzioni UI, in futuro upscaling (in arrivo) |
| `_local/` | **Non in git.** Client estratto, Ghidra, JDK, risultati del reverse engineering |

Stato e piano: [wiki/wiki/concepts/Roadmap v1.0.0.md](wiki/wiki/concepts/Roadmap%20v1.0.0.md).

I file del client di gioco non sono e non saranno mai in questa repository.
