# Universal Modder

Skill e strumenti per agenti AI che modificano giochi PC (rehan-remade/universal-modder, MIT). Copia in `_local/tools/universal-modder`.

Utile per noi: la skill `reverse-engineering`, `game-recon`, `game-automation` (test in gioco automatici) e la base di conoscenza `knowledge/` (note su motori e tecniche). La parte di generazione grafica (fal) richiede una chiave fal: non serve ora.

Installazione come plugin di Claude Code (da fare tu nel terminale `claude`):
```
/plugin marketplace add rehan-remade/universal-modder
/plugin install universal-modder@universal-modder
```
