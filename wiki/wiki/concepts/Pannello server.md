# Pannello server

Pagina web servita dal server stesso: si apre dal browser del PC o dal telefono.

Requisiti (da [[Lezioni da DaProd]]):
- **Responsive**: tabelle che si adattano, pulsanti raggruppati in menu, niente scorrimento orizzontale.
- **Aggiornamento in tempo reale** (giocatori online, zone, log) piu' pulsante "Aggiorna" ovunque.
- Ogni azione (oro, livello, GM, oggetti, onore, vocazione) funziona **sia online sia offline**, perche' passa sempre dal server vivo ([[Architettura server]]).
- Regole del gioco modificabili a caldo.
- Assistente opzionale con [[Needle]]: comandi in linguaggio naturale.
